# 🌐 MediaFlow Landing Page

Landing page da **MediaFlow**, criada com HTML e CSS puro.

## 🚀 Como publicar no GitHub Pages

1. Crie um repositório no GitHub (público).
2. Envie o conteúdo desta pasta (`index.html` e este README.md`) para o repositório.
3. Vá em **Settings → Pages**.
4. Em "Source", escolha **Deploy from a branch**.
5. Branch: `main`, Folder: `/ (root)`.
6. Clique em **Save**.

Depois de alguns minutos, o site ficará disponível em:

```
https://SEU_USUARIO.github.io/NOME_DO_REPOSITORIO
```
